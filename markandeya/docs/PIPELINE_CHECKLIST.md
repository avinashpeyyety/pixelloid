1. **Script** — `episodes/<id>/script.js` (`EPISODE` with beats, `voice.voice_id: "orion"`, `music.raga`), generated by the
   box builder `/home/box/lab-keep/pixelloid-build/mpNN-build/build.py markandeya/`.

3. **Cast + bible** — `cast-sheet.json`, `plate-bible.json` (faces from `config/cast-locks.json`).
4. **GATE A/B** — `python3 tools/logic_review.py episodes/<id>/plate-bible.json --report` → PASS.

   `episodes/<id>/stills/_inbox/consumer-imagine/PROMPTS.md` (3:2 Photo Print, ≥1536×1024, ≤5 refs, in order) and saves
   the exact filenames into that `_inbox/consumer-imagine/` folder. Never api.x.ai.

8. **GATE C** — `python3 tools/stills_review.py episodes/<id> --require` → PASS; eye-check every plate and fill
   `logic-reviews/RR-gateC-visual.md` from `docs/GATE_C_TEMPLATE.md` (watermark, arms/hands, locks, no gore).
9. **Thumbs** — `python3 tools/make_thumbs.py episodes/<id>`.
10. **GATE D install** — `python3 tools/install_review.py episodes/<id> --report` → PASS (Orion voice id, raga, every
    plate + clip on disk).
11. **Ship** — `js/episodes.js` status `"live"`; add `EP_LOADERS` entry (if new); bump `?v=` in `index.html`, `play.html`,
    `js/landing.js`; local smoke (`python3 -m http.server` from repo root → `/markandeya/play.html?ep=NN`, 0 console errors);
    write `logic-reviews/RR-ship.md`; merge the `studio/markandeya-epNN` branch into `main` and push (GitHub Pages deploys
    on push to main). Live: `https://avinashpeyyety.github.io/pixelloid/markandeya/play.html?ep=NN`.
