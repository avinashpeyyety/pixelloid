# Chocolate Dance School 🍫💃

Professor **Cocoa** teaches a class of silly chocolates how to dance. Built for kids — goofy moves, jokes, confetti, and optional bouncy music.

Part of **[Pixelloid](../)** (kids entertainment animations).

## Run

From this folder (or the pixelloid root):

```bash
cd pixelloid/chocolate-dance
python3 -m http.server 8768
```

Open **http://127.0.0.1:8768**

## Controls

| | |
|--|--|
| **Start class** | Run the ~1 minute dance lesson |
| **Music** | Procedural dance jam (Web Audio — no files) |
| **Again** | Reset |
| Drag / scroll | Orbit camera |

## Cast

- **Professor Cocoa** — glasses, hat, bow tie (knows the moves)
- **Chip** — classic bar, sticky from fondue
- **Truffle** — round, no left or right
- **Minty** — green, becomes a breath-mint tornado
- **Whitey** — fancy butter with dreams

## Stack

Three.js r170 (CDN) · Web Audio API · Fredoka font
